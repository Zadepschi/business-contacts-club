# Клуб деловых контактов

Небольшой сайт на Next.js из трёх страниц:

- `/` — главная
- `/about` — о клубе и форматах встреч
- `/join` — как вступить и правила

## Запуск на компьютере

1. Установите Node.js (LTS): https://nodejs.org/
2. Откройте терминал в папке проекта.
3. Выполните:

```bash
npm install
npm run dev
```

4. Откройте в браузере http://localhost:3000

## Ссылка на Facebook

Скопируйте `.env.example` в `.env.local` и замените значение на настоящую ссылку:

```env
NEXT_PUBLIC_FACEBOOK_GROUP_URL=https://www.facebook.com/groups/ВАША_ГРУППА
```

После изменения `.env.local` перезапустите `npm run dev`.

## Что нужно заменить перед публикацией

- Ссылку Facebook в `.env.local`.
- Демонстрационные фотографии на фотографии клуба.
- При необходимости название клуба и тексты.
- Добавить реальные контакты организатора, если хотите показывать их на сайте.

Фотографии сейчас загружаются с Unsplash как временные иллюстрации.
